### [ ] Понять, по какому принципу выбираются порты для исходящих соединений.   
Когда мы подключаемся по TCP, указываем конечный адрес в виде хоста с портом, но нужно и нам как-то обозначиться, тк мы ничего не указываем сами обычно \
Поэтому ОС и выставляет порт отпрвителя автоматически \
Это эфемерный порт\

Диапазоны портов:
0-1023: привилегированные порты (ssh, http, https и тд) \
1024-N - за приложениями \
N-M - динамические или эфемерные, отсюда OS берет исходящие порты \

для MacOs, например, 49152-65535 (N-M) \
Linux 32768-60999 \

раньше выбирались по очереди например с 49152++, теперь ОС рандомизируют этот процесс, чтобы защититться от атак угадывания или предсказания порта при соединениях \
выбирают, конечно, уникальный рандомный порт \

`grep -rhoE` : \
r - рекурсивно \
h - не печатать имя файла \
o - вывести только совпавшую строку а не все \
E - extended расширенные регулярки, далее их и используем : \
`grep -rhoE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' /var/log ` \

`grep -rhoE '[0-9]+\.[0-9]+\.[0-9]+\.[0-9]+' /var/log | grep -v '^10\.'` \
-v = инверсия \
^ - начало строки \
